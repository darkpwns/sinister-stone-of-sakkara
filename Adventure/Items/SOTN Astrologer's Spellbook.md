# SOTN Astrologer's Spellbook

Judge-only. SOTN item (H16 scroll jar; [[SOTN Magic Items#Astrologer's Spellbook]], SOTN p. 137): vellum sheets
stitched in a roll, Ancient Argollëan left to right in gold and black ink, star charts in the borders; ebony handles
set with tiny star-like crystals; silver cord. Not encrypted (SOTN gives no cipher; Judge's call): a mage who reads
Ancient Argollëan reads it. Value 25,900gp, 3/6 st. SOTN: spellbooks count as treasure for XP only when sold. Apparent
value 250gp (a fine old scroll on ebony handles; Judge's call).
