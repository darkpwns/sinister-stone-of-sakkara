# SOTN Transmogrifier's Spellbook

Judge-only. SOTN item (E3 dais compartment; [[SOTN Magic Items#Transmogrifier's Spellbook]], SOTN p. 137): vellum
sheets stitched in a roll between two glyph-carved bone handles, green ink right to left; encrypted Ancient
Argollëan (gibberish until deciphered by magic or magic research). Value 31,750gp, 3/6 st. SOTN: spellbooks count as
treasure for XP only when sold. Apparent value 250gp (a fine old scroll on carved bone handles; Judge's call).
