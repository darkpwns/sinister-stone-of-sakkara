# campaign.yaml schema

Load to check a config key or to write a campaign's config. Not needed in play: the scripts read the config themselves.

All paths are relative to the campaign repo.

| Key | Meaning |
| --- | --- |
| `campaign` | `name`, `repo`, `clone_dir`, `resume_phrase`, `chat_name`, `commit_prefix` |
| `rules` | rules `repo`, `clone_dir`, `lookup_skill`, `supplements`, `warfare` chapter path |
| `tools` | rules engine `repo`, `ref` (the branch `setup.sh` puts the tools clone on), `min_version` (the oldest engine the campaign runs on; actors need 7.x), `hexes` (the file whose `hexes:` block the engine's adapter reads), `travel` (dawn, moon), `clone_dir`, `setup`, `wrapper`, `combat_state` (acks-combat/3 JSON, Judge only), `exploration_state` (acks-exploration/3 JSON, Judge only), `retinue_state` (acks-retinue/2 JSON, Judge only: employers, candidates, henchmen and hirelings with loyalty, morale and wages), `candidates` (draft actors, Judge only), `actor_changes` (folder of the actors' archived change logs, Judge only; `save.sh` moves them there at a session-end save), `adventure_state` (acks-adventure/2 JSON, Judge only: the open adventure, treasure lots with true and player records, unfound hoards, monsters defeated, market sales by month, reserve XP funds), `inventory_state` (acks-inventory/2 JSON, Judge only: every holder's possessions and coins as a log of events), `treasure` (`setting` classic/heroic/gritty from Table rules, `arms_setting`: the Magic Arms and Armor Types column), `engine_rulings` (acks-rulings/1 YAML), `bestiary` (optional: folders of campaign or module creature notes with statblocks; `acks.sh` passes each as `--bestiary` to `state`, `encounter` and `monster`, and exports them as ACKS_BESTIARY for every command), `items` (optional: folders of module magic item notes, exported as ACKS_ITEMS), `overlay` and `term_map` (optional: the display overlay; without `overlay` the overlay check is skipped), `class_aliases` and `race_aliases` (optional: campaign name → RR class or race for classes played under campaign names; `acks.sh` passes campaign.yaml as `--aliases`), `coverage`  Optional (engine 7.16.0+): `lessons` (the lessons index, default `Campaign/lessons.yaml`), `schedule` (recurring procedures, default `Campaign/schedule.yaml`), `tables` (folders of campaign tables for `table roll` and door kinds; default: every `Tables/` folder under `paths.sites_folder`); `logs.handoff` (the one handoff file, default `Campaign/handoff.md`). Each is used only if the file exists. |
| `start` | `year`, `season`, `day`, `time`, `mode`, `location` (wiki link), `hex` |
| `paths` | `home`; `wiki_folders` (world, region, places, people, factions, realms, markets, dynamic_lairs, tables, secrets, sessions, build_notes, templates, maps); `sites_folder`; `state` (campaign_state, world_state, rulings, ledger, roll_log, snapshot); `characters` (PC and henchman actors, published); `actors` (the actor folders, in order: an actor id names `<folder>/<id>.json`; `acks.sh` passes them as ACKS_ACTORS); `class_notes` (optional: one note per reskinned class, player sections plus Judge-only callouts); `calendar` |
| `secrecy` | `judge_only_folders`, `judge_only_files`, `judge_only_tag`, `judge_only_callout`, `player_facing`, `revealed` |
| `logs` | `session_log` (folder, template, filename, index, index_section, judge_block); `rumours` (note, section); `story_strands` (note); `clocks` (note, column, when) |
| `procedures` | `overland` (`core` or a note path), `flags` (note or `none`), `procedure_notes`, `weather` (source and climate rule; the engine rolls it and applies its effects) |
| `hexes` | `csv`, `numbering`, `offset`, `columns` (role → CSV column), `roads`, `navigable_rivers`, `places`, `terrain_map`, `columns.encounters` (optional: a hex's own encounter procedure, `DIE N+ TABLE`) (CSV terrain code → `acks:` the ACKS terrain type the engine maps to every table row), `river_encounters`, `climate` (by column), `weather_region` (size), `settlements` (types) — the engine's hex adapter reads this block (`tools.hexes`) |
| `party` | `structure` (solo-henchmen, human-party, ai-party, mixed), `caller`, `user_pc`, `active_players` (`{id, pc}`), `pc_pdf_template`, `pc_pdf_source`, `agent` (call, model, base_prompt, profiles, heuristics, memory, party_notes, call_dir, call_log, retries, rules_refused) |
| `display` | `artifact_slug`, `artifact_url`, `db_doc`, `schema`, `rules`, `payload_file` (optional: where `save.sh` writes the db document for the write's `file_path`; default `/tmp/acks-display-payload.json`) |
| `brief` | optional: `rulings_rows` (default 8), `world_sections` (default `["Prep queue", "NPC attitudes", "Scheduled events:12"]`), `tails` (default `["Playtest/judge-notes.txt:8"]`), `session_lines` (default 40) |
